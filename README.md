# CAP776 - My Data, My Story

## Personal Activity Intelligence Report

This is my minor project for **CAP776: Programming in Python**.

The main purpose of this project is to record my daily activities and use Python to understand how I spend my time on sleep, study, coding, classes, fitness and other activities.

## About the Project

I maintained daily activity data in an Excel file for 40 days, from **13 August 2026 to 21 September 2026**.

The Python program reads the data from the Excel file and calculates different averages and activity indexes.

The project also looks at some simple relationships between my daily activities, such as:

- Sleep and Energy
- Study and Satisfaction
- Coding and Energy

## Technologies Used

- Python
- Excel
- OpenPyXL
